# Nawar Mohra — One-page Portfolio

A responsive, accessible static portfolio inspired by the bold typography, minimal palette, smooth reveals, and editorial rhythm of Dennis Snellenberg's portfolio — without copying its source code or exact design.

## Run locally

Open `index.html` directly, or start a small local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
